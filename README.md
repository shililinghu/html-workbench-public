# html-workbench-public

Local block based HTML page editor.

This public edition contains reusable source only, with independent Git history. Read [PRIVACY.md](PRIVACY.md) before configuring it.

Original runtime configuration, personal data and media are intentionally absent. Install dependencies listed by the included package or requirements files and supply your own local settings. Examples are fictional.

## Usage

Work in `app/`. Run `npm test` and `npm start`, then use the loopback URL printed by the server. Provider settings are entered locally in the application.
